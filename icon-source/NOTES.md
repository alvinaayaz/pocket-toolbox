# Icon source files
- `master.svg`: the refined toolbox artwork (vector, edit in any SVG editor, Figma, Illustrator or Inkscape)
- `maskable.svg`: same artwork scaled to 88% so the Android adaptive-icon mask can never clip the handle
- `favicon.svg`: same artwork scaled up 120% so it stays readable at 16 and 32 pixels
- `toolbox-master.png`: 1024 px render of the master

icon-192.png, icon-512.png and apple-touch-icon.png come from master.svg.
icon-512-maskable.png comes from maskable.svg. favicon.ico (16, 32, 48 px) and favicon-32.png come from favicon.svg with rounded corners.
